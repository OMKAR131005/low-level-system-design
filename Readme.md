# LLD & Design Patterns Journey 🚀

This repository is my learning log for **Low Level Design (LLD)** and **Design Patterns**, built in **Java**.
I'm using this space to practice writing clean, extensible, and interview-ready object-oriented designs — one concept at a time.

## 🎯 Why this repo?

I'm preparing for campus placements, and LLD rounds are a big part of the process. Instead of just reading theory, I'm implementing each concept from scratch, writing notes on when/why to use it, and revisiting classic problems (parking lot, elevator system, etc.) to apply what I learn.

## 📖 How I'm Approaching This

1. Pick a pattern or problem.
2. Understand the intent — what problem does it solve, and why does it exist?
3. Implement it in Java with a simple, realistic example.
4. Write short notes on trade-offs and when to (not) use it.
5. Revisit and refactor as I learn more.
